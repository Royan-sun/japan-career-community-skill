# Japan Career Community Skill

一个面向在日中国留学生的免费 AI Skill：把真实的留学、研究与日本求职经验整理成可复用的决策框架、行动清单与表达模板。

## 项目目标

很多留学生真正缺少的不是“更多信息”，而是：

- 不知道下一步应该做什么；
- 信息分散，很难判断哪些适合自己的情况；
- 面对 ES、面试、研究计划、学校行政等任务时，不知道如何把个人经历转化为可提交的表达；
- 同一个问题在社群中被反复询问，却很难沉淀成可复用知识。

本项目通过 AI 协作，把个人经验整理成一个可迭代的 Skill，并免费分享给社群成员。Skill 提供结构化提问、行动建议、模板和检查清单；社群反馈再反向用于更新 Skill。

## AI 如何参与

AI 主要负责：

1. 将零散经验归纳为流程、判断标准和模板；
2. 对同一问题生成不同场景下的表达方案；
3. 检查内容是否遗漏关键条件；
4. 根据社群反馈持续重构 Skill 的知识结构与提示词。

人工负责：

- 判断哪些建议来自真实经历、哪些只是通用信息；
- 删除不可靠或不适用于日本语境的内容；
- 对重要结论进行事实核验；
- 决定最终对外发布的内容与服务边界。

## 当前 MVP 模块

### 1. 日本求职行动导航
根据用户所处阶段，输出下一步优先级：企业筛选、ES、Web Test、面试、Offer 比较等。

### 2. ES / 面试经验结构化
把用户的经历整理为“背景—行动—结果—反思”，并适配日企常见问题。

### 3. 研究生生活与行政任务清单
整理在日留学生常见的研究、学校沟通、奖学金/行政手续等任务，强调信息核验与学校官方渠道优先。

### 4. 社群问答沉淀
把社群中的高频问题转化为 FAQ、模板与新 Skill 模块，形成持续迭代的知识库。

## 使用方式

将 `SKILL.md` 作为系统提示或项目说明加载到支持自定义指令的 AI 工具中，然后直接提问。例如：

- “我现在是修士二年级，想投东京的互联网公司，帮我安排两周求职优先级。”
- “把这段实习经历整理成日企 ES 用的ガクチカ，但不要替我编数据。”
- “我第一次参加日本公司的面试，请根据我的经历帮我做追问清单。”

## 社群运营闭环

免费 Skill → 社群分享 → 用户实际使用 → 收集高频问题与反馈 → 更新 Skill → 建立专业信任。

如果用户希望得到更个性化、需要深入沟通的支持，可以进一步了解项目发起者提供的个人服务；免费内容本身保持可独立使用，不以强制付费为前提。

## 项目原则

- 不虚构用户经历、成绩、企业结果或数据；
- 不替代学校、企业、政府机构的官方信息；
- 涉及签证、法律、税务、医疗等高风险事项时，明确提示用户核验官方来源；
- 优先帮助用户形成自己的判断，而不是只给“标准答案”。
