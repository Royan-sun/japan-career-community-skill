# Japan Information Design Admission Skill

面向中国本科大三、大四学生的免费 AI Skill：帮助理解日本综合类大学中的「情報デザイン」相关研究，找到真正的研究兴趣，筛选学校与教授，并逐步完成研究计划书、套磁、作品集与考试准备。

> 核心不是“替你选学校”，而是先帮你找到：**你到底想研究什么。**

## 为什么做这个项目

日本很多综合类大学并不会把相关方向直接命名为「情報デザイン」。相似研究往往分散在情報学、デザイン学、学際系、工学系、人間情報、感性工学、メディア等研究科和研究室中。

因此，国内学生常见的信息差不是“完全找不到学校”，而是：

- 只知道 UI / UX、数据可视化，却不了解情报设计还有很多研究分支；
- 看见别人学某个方向就跟风，却没有形成自己的研究兴趣；
- 不知道综合类大学和美术大学的准备逻辑差异很大；
- 只看学校名气，不看考试制度、研究室和教授是否匹配；
- 设计背景学生容易把作品集放在第一顺位，但综合大学往往更重视研究计划、研究匹配和考试；
- 转专业学生容易因为“本科不对口”先自我劝退，其实小型 demo、课程项目或实践也可以证明研究潜力；
- 把大量思考交给 AI，最后研究计划和面试回答并不是自己的判断。

这个项目把真实考学与辅导经验整理成一个可复用的 Skill，并在社群中免费分享，通过用户问题和反馈持续迭代。

## 适用范围

主要面向：

- 国内大三 / 大四，计划申请日本大学院的学生；
- 目标以**综合类大学中的信息设计、设计学、HCI、交互、媒体、人间信息等方向**为主；
- 可以是设计背景，也可以是跨专业申请；
- 不以美术大学的作品集型考学作为主要对象。

## 三阶段流程：Discover → Match → Apply

### 1. Discover｜先找到真正的研究兴趣

不直接问“你想学什么专业”，而是从既往经历出发。

- 非设计背景：追溯为什么选择原专业、四年里做过什么、什么经历触发了转向；
- 其他设计专业：寻找原专业和数字媒体 / HCI / AR / VR / AI / 感性等方向的连接；
- 本来就在相关领域：减少说教，以倾听和梳理已有兴趣为主。

输出 2–3 个可能方向，并进一步给出真实论文、研究项目、实验室和视频案例，让学生理解“现实产品里的 VR / AI / UX”和“科研中的 VR / AI / UX”有什么区别。

### 2. Match｜先学校，再考试制度，再教授

本项目不采用“先找到教授就推荐报考”的简单逻辑。

原因是：研究内容很匹配，不代表学生现实中能准备这套入试。例如某些情報学相关项目要求数学或专业笔试，对没有相应基础的设计学生准备成本会很高。

因此流程为：

`研究方向 → 候选学校 → 入试制度检查 → 教授 / 研究室匹配 → 难度修正 → 冲刺 / 主申 / 稳妥组合`

第一轮检查包括：

- 数学 / 专业笔试；
- 日语与英语要求；
- 作品集要求；
- 研究计划书要求；
- 是否需要事前联系教授；
- 出愿与考试时间；
- 招生人数和官方报录比。

随后再检查教授当年是否招生、研究室竞争度、内部生倾向、往届经验等。

### 3. Apply｜把方向转成申请材料

核心包括：

- 研究计划书；
- 先行研究检索；
- 研究方法匹配；
- 教授套磁；
- 作品集与 demo；
- 笔试 / 面试准备。

## 情报设计的分类

本 Skill 会引导用户探索例如：

- AR / VR / MR、具身交互；
- HCI、UX 与新型界面；
- 感性工学与人的主观感受；
- 服务设计；
- 医疗 / 健康相关设计；
- 数字媒体与互动装置；
- 产品设计 × 数字技术；
- 视觉传达 × 数字媒体；
- AI × Design；
- 其他与“人—社会—技术关系”相关的交叉研究。

这些只是入口，不把学生强行塞进固定标签。

## 教授匹配：三层验证

判断教授不能只看个人主页上的几个关键词。

建议交叉查看：

1. **Researchmap**：近两年的论文与成果；
2. **KAKEN**：当前或近期科研费课题，判断教授现在真正投入什么研究；
3. **研究室官网**：研究主题、项目、学生课题和近期活动。

匹配主要看**研究主题**和**研究方法**。大方向相似不等于真正匹配。

## 研究计划书方法论

审查老师本质上在确认四件事：

1. 这个问题重要吗？
2. 前人做到哪里、还缺什么？
3. 你具体要做什么、怎么做？
4. 做出来有什么用？

标准结构：

`研究背景 → 先行研究 → 研究目的 → 研究方法 → 期待成果・意義 → 年次計画・参考文献`

核心逻辑链：

`现状 → 但是仍有不足 → 因此本研究要做什么 → 先行研究证明缺口 → 具体怎么验证 → 有什么意义`

经验上的优先级：**教授 / 研究方向匹配 > 选题的新鲜感与创新度 > 两年内可实现性 > 方法写得多复杂。**

研究题目不应一开始就试图“做一个完整 App”或“解决一个宏大社会问题”，尤其是转专业学生。更建议从一个可以验证的小问题开始。

## 先行研究检索

先梳理“我需要文献证明什么”，再找文献，而不是搜到什么就引用什么。

常用路径：

`研究问题拆解 → 关键词 → Google / CiNii / ACM DL 等检索 → 筛选新论文 → 查看引用与参考文献 → 扩展相关研究 → 同时发现潜在教授`

论文不是用来凑数量的，每篇文献都应该在研究计划书里承担一个角色。

## 作品集原则

综合大学的作品集首先服务于研究计划书：**证明你有能力把研究做出来。**

推荐优先级：

`研究计划相关项目 → 相关 demo / 技术尝试 → 其他交互 / 信息设计项目 → 原专业传统作品`

如果过去没有相关作品，而计划做 VR、AR、AI 或其他技术型研究，可以先做一个小 demo。demo 不必复杂，重点是证明已经动手尝试，并理解基本实现逻辑。AI 可以帮助降低原型试错成本，但学生必须理解自己做了什么。

## 套磁原则

- 一般建议在出愿截止前约 1–2 个月开始联系；
- 研究计划书是核心附件；
- 建议同时准备 CV、作品集、成绩单、语言成绩等；
- 邮件必须体现“为什么是这个教授”，不要只换名字群发；
- 教授姓名、学校、研究科、附件、发送时间都要人工检查；
- AI 可以辅助起草，但不能不检查就直接发送；
- 同一学校、同一研究科原则上不要同时给多位教授套磁。

## 学生画像与 Ready Check

正式选校前会了解：年龄、毕业院校、本科专业、工作经历、日语 / 英语、GPA、研究方向 / 研究计划、相关项目或实践。

但学校出身、GPA、是否转专业通常不作为简单的一票否决。

真正重要的前置条件是：

- 至少有一种语言能支撑研究交流；
- 对情报设计不是“拍脑门决定”，而是已经开始理解这个领域并有真实兴趣。

如果尚未满足，就先回到 Discover，而不是急着给学校名单。

## 转专业原则

**既往专业是线索，不是限制。**

转专业学生不需要一开始就有大型成果。课程项目、作品、毕业设计、自学、小 demo、工作坊、实习或一次很小的实践都可以作为“我已经开始进入这个领域”的证据。

比“专业名称对口”更值得看的，是**实际经历与研究兴趣能否连起来**。

## 常见误区

- 完全不思考，把研究方向、计划书和判断全部交给 AI；
- 只考 1～2 所学校，导致整体风险过高；
- 把情报设计理解成 UI / UX 或数据可视化的同义词；
- 用美术大学逻辑准备综合大学；
- 只看学校名气，不看考试机制；
- 把作品集放在研究计划和教授匹配之前。

## 信息核验原则

以下信息必须按**当年度**重新检索，不使用旧信息冒充当前情况：

- 出愿时间与募集要项；
- 考试科目；
- 语言要求；
- 招生人数与官方报录比；
- 是否需要教授事前同意；
- 教授当年是否招生；
- 研究室当前主题。

优先级：**学校 / 研究科官方页面 > 研究室官方页面 > Researchmap / KAKEN / CiNii / 学术数据库 > 往届经验。**

前辈经验可以补充真实考试体感，但不能替代官方信息。

## 一次完整诊断的输出

理想情况下，Skill 最终会给学生：

- 学生背景与当前准备度总结；
- 2–3 个推荐研究方向；
- 每个方向的真实论文 / 项目 / 视频案例；
- 推荐关注的教授和研究室；
- 冲刺 / 主申 / 相对稳妥的学校组合；
- 当前能力缺口；
- 建议补充的小型 demo 或实践；
- 接下来 3–6 个月行动计划。

## AI 与人的分工

**AI：** 信息检索、资料整理、兴趣追问、文献解释、方法匹配、逻辑检查、原型辅助、面试模拟。

**学生 / 经验提供者：** 兴趣判断、经历真实性、研究价值判断、申请策略决策、材料最终确认。

本项目最重要的一条原则是：**AI 可以帮助思考，但不能替人思考。**
