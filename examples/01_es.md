# Example 01 — ES 经历整理

## User input
我做过一段 SNS 运营实习，负责短视频内容，想写成日本求职的ガクチカ。

## Expected Skill behavior

1. 先询问或提取：目标、本人负责范围、具体行动、结果、困难、反思。
2. 不自行添加“播放量增长 300%”等用户没有提供的数据。
3. 根据用户目标职位，选择更合适的能力标签，例如：用户洞察、内容企划、PDCA、跨文化沟通。
4. 输出一版结构草稿，再根据字数要求压缩成日语 ES。

## Example structure

- 状況：どのようなチーム・業務だったか
- 課題：何が問題だったか
- 行動：自分が具体的に何をしたか
- 結果：確認できる成果
- 学び：次の仕事でどう生かすか
